# 项目启动清单

## 1. 开发环境准备

### 1.1 环境要求

- Node.js >= 20.x
- PostgreSQL >= 15（需支持 pgvector 插件）
- Redis >= 7.0
- Git

### 1.2 阿里百炼配置

1. 访问 https://dashscope.console.aliyun.com/
2. 创建 API Key
3. 记录以下信息：
   - `DASHSCOPE_API_KEY`
   - 可用模型：`qwen-max`、`qwen-vl-max`（图片）、`text-embedding-v2`

## 4. 环境变量配置

### 后端 .env

```env
# 服务器
PORT=3000
NODE_ENV=development

# 数据库
DATABASE_URL="postgresql://user:password@localhost:5432/assistant?schema=public"

# Redis
REDIS_URL="redis://localhost:6379"

# JWT
JWT_SECRET="your-secret-key-change-in-production"
JWT_EXPIRES_IN="7d"

# 阿里百炼
DASHSCOPE_API_KEY="your-api-key"
DASHSCOPE_CHAT_MODEL="qwen-max"
DASHSCOPE_EMBEDDING_MODEL="text-embedding-v2"

# 文件存储（本地开发）
STORAGE_TYPE="local"
STORAGE_UPLOAD_PATH="./uploads"

# 文件存储（生产环境 OSS）
# STORAGE_TYPE="oss"
# OSS_BUCKET="your-bucket"
# OSS_ENDPOINT="oss-cn-hangzhou.aliyuncs.com"
# OSS_ACCESS_KEY="xxx"
# OSS_SECRET="xxx"
```

### 前端 .env.development

```env
VITE_API_BASE_URL=http://localhost:3000/api/v1
```

## 5. 快速开始命令

```bash
# 后端
cd backend
npm install
npx prisma migrate dev
npm run start:dev

# 前端
cd frontend
npm install
npm run dev
```
