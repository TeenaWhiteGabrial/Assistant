## 一、前端技术

### 1. React - 构建界面的框架

**是什么：**
- Facebook 开发的 UI 框架，用来构建网页界面
- 核心思想：把页面拆成一个个"组件"，像搭积木一样拼起来

**举个栗子：**
```jsx
// 一个简单的按钮组件
function MyButton({ text, onClick }) {
  return <button onClick={onClick}>{text}</button>;
}

// 使用组件
<MyButton text="发送" onClick={handleSend} />
```

**为什么选它：**
- 生态最丰富，组件多
- 好找工作，好招人
- 适合复杂应用

---

### 2. TypeScript - 带类型的 JavaScript

**是什么：**
- JavaScript 的超集，给代码加"类型检查"
- 微软开发，现在前端基本都用它

**对比一下：**
```javascript
// JavaScript - 容易出错
function add(a, b) {
  return a + b;  // 如果传入 "1" + 2 会得到 "12" 😱
}
```

```typescript
// TypeScript - 编译器会检查类型
function add(a: number, b: number): number {
  return a + b;  // 如果传入字符串会直接报错 ✅
}
```

**为什么选它：**
- 减少 bug
- IDE 自动补全更智能
- 重构代码更安全

---

### 3. Vite - 开发和打包工具

**是什么：**
- 法语意思是"快速"
- 新一代前端构建工具，替代传统的 Webpack

**好在哪：**
| 工具 | 启动时间 | 热更新 |
|------|----------|--------|
| Webpack | 30 秒 + | 3-5 秒 |
| Vite | 1 秒 | 瞬间 |

**为什么选它：**
- 开发体验好，不用等
- 配置简单

---

### 4. TailwindCSS - 写样式的方式

**是什么：**
- 原子化 CSS 框架，直接用类名写样式

**对比一下：**
```css
/* 传统方式 - 要写 CSS 文件 */
.button {
  background-color: blue;
  color: white;
  padding: 10px 20px;
  border-radius: 5px;
}
```

```html
<!-- Tailwind - 直接写类名 -->
<button class="bg-blue-500 text-white px-5 py-2 rounded">
  点击
</button>
```

**为什么选它：**
- 不用想起类名
- 样式统一
- 开发快

## 二、后端技术

### 1. NestJS - Node.js 的企业级框架

**是什么：**
- 基于 Node.js 的后端框架
- 使用 TypeScript
- 提供清晰的代码组织结构

**代码长什么样：**
```typescript
// 一个简单的接口
@Controller('users')
export class UserController {
  @Get()
  getUsers() {
    return [{ id: 1, name: '张三' }];
  }
}
// 访问 /users 就返回上面的数据
```

**为什么选它：**
- 结构清晰，好维护
- 内置很多功能（认证、验证、拦截器）
- 适合中大型项目

---

### 2. Prisma - 数据库操作工具

**是什么：**
- 新一代 ORM（对象关系映射）
- 用 TypeScript 操作数据库，不用写 SQL

**对比一下：**
```sql
-- 传统 SQL
SELECT * FROM users WHERE id = 1;
```

```typescript
// Prisma - 像操作 JavaScript 对象
const user = await prisma.user.findUnique({
  where: { id: 1 }
});
```

**为什么选它：**
- 类型安全
- 自动补全
- 数据库迁移方便

---

### 3. PostgreSQL - 关系型数据库

**是什么：**
- 开源的关系型数据库
- 功能强大，支持 JSON、向量等高级特性

**能做什么：**
```sql
-- 存用户
INSERT INTO users (id, username, email)
VALUES ('uuid-123', '张三', 'zhangsan@example.com');

-- 查询
SELECT * FROM entries WHERE user_id = 'uuid-123'
ORDER BY created_at DESC;
```

**为什么选它：**
- 稳定可靠
- 支持 pgvector 插件（存 AI 向量）
- 性能好

---

### 4. pgvector - 向量存储插件

**是什么：**
- PostgreSQL 的插件
- 用来存储和搜索"向量"（AI 生成的数字数组）

**向量是什么：**
```
文本："今天天气不错"
→ AI 转换成向量 → [0.123, -0.456, 0.789, ...] (1024 个数字)

文本："天气很好"
→ AI 转换成向量 → [0.125, -0.453, 0.787, ...]

→ 两个向量很接近 → 说明意思相近
```

**能做什么：**
- 语义搜索："找出去年的聚餐照片"（即使照片没打标签）
- 相似内容推荐

## 三、外部服务

### 阿里百炼 (DashScope)

**是什么：**
- 阿里云的 AI 平台
- 提供大模型 API

**本项目用到的能力：**
| 能力 | 模型 | 用途 |
|------|------|------|
| 对话 | qwen-max | 理解用户输入，生成回复 |
| 图片识别 | qwen-vl-max | 识别照片内容、OCR |
| 文本向量 | text-embedding-v2 | 生成向量，用于搜索 |

**调用示例：**
```typescript
// 调用 AI 理解用户输入
const response = await dashscope.chat({
  model: 'qwen-max',
  messages: [{
    role: 'user',
    content: '帮我记录：今天打车花了 35 块'
  }]
});
// AI 返回：{"type": "bill", "amount": 35, "category": "交通"}
```

   - 模块系统

- 跟着项目一步步实现

## 六、常见问题

**Q: 这些技术我都没学过，能学会吗？**
A: 可以。这些技术都是现代开发的主流，学习曲线平缓。而且本项目可以从简单开始，边做边学。

**Q: 有没有更简单的方案？**
A: 有更简单的，但会牺牲扩展性。既然要做多端互通的项目，一开始搭建好架构很重要。

**Q: 先学哪个？**
A: 建议顺序：TypeScript → React → NestJS。但如果着急开始，可以直接从项目实战中学。

**Q: 开发环境怎么配？**
A: 只需要安装 Node.js，其他工具都会通过 npm 自动安装。

## 七、术语表

| 术语 | 解释 |
|------|------|
| 前端 | 运行在浏览器的部分，用户能看到的界面 |

| API | 前后端通信的接口 |
| 数据库 | 存储数据的地方 |
| ORM | 用代码操作数据库的工具 |
| 组件 | UI 的基本单元，比如按钮、输入框 |
| Hook | React 的特殊函数，用来处理状态 |
| 路由 | 决定哪个 URL 显示哪个页面 |
| JWT | 一种用户登录验证的方式 |
| 向量 | AI 生成的数字数组，用于语义搜索 |
