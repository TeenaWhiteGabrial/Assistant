# AI 个人助手项目规划

## 1. 项目愿景

打造一个以 AI 为核心引擎的、多端互通的个人智能助手，让用户能够随时随地通过任意设备记录生活、管理工作、存储知识，AI 自动理解、整理并反馈用户的个人数据。

---

## 2. 核心功能模块

### 2.1 输入通道（多端采集）

| 端口 | 功能 | 技术选型建议 |
|------|------|-------------|
| 网页端 | 照片上传、文本笔记、语音输入 | React/Vue + PWA |
| PC 客户端 | 拖拽上传、剪贴板集成、全局快捷键 | Electron/Tauri |
| 微信小程序 | 拍照上传、语音转文字、快速入口 | 原生小程序 |
| 手机 APP | 原生相机、语音助手、通知推送 | Flutter/React Native |

### 2.2 AI 核心引擎

- **意图识别**: 解析用户输入，判断是记账、备忘录、日报还是其他类型
- **数据提取**: 从非结构化文本/图片中提取结构化数据
- **智能回复**: 基于上下文生成自然语言反馈
- **任务调度**: 定时提醒、周期性任务管理

### 2.3 数据存储层

| 数据类型 | 存储方案 | 说明 |
|----------|----------|------|
| 用户数据 | PostgreSQL/MySQL | 账户、配置、权限 |
| 业务数据 | PostgreSQL + MongoDB | 结构化 + 半结构化数据 |
| 图片/文件 | 对象存储 (MinIO/OSS) | 照片、附件 |
| 向量数据 | pgvector/Milvus | AI  embeddings，支持语义搜索 |
| 缓存层 | Redis | 会话、热点数据 |

### 2.4 功能场景

1. **备忘录**: AI 自动提取时间、地点、事项，设置提醒
2. **记账**: 从消费小票/文本中自动识别金额、分类、商户
3. **工作日报**: 汇总当日记录，生成结构化日报
4. **旅游规划**: 基于用户偏好和约束条件生成行程
5. **照片管理**: AI 识别场景、人物、文字，支持语义搜索
6. **个人知识库**: 文档存储 + 向量检索，支持问答

## 4. 技术栈建议

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| 后端框架 | NestJS / FastAPI | TypeScript/Python 生态，AI 集成友好 |
| AI 模型 | Claude API / 本地部署 Qwen | 强大的理解与生成能力 |
| 向量数据库 | pgvector | 与 PostgreSQL 一体，降低运维成本 |
| 实时通信 | WebSocket / SSE | 支持流式响应 |
| 部署 | Docker + K8s | 容器化、弹性伸缩 |
