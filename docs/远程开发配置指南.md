## 一、方案概述

### 工作原理

```
┌─────────────────┐         SSH 连接          ┌─────────────────┐
│   宿舍 Mac      │ ←───────────────────────→ │   公司 Windows   │
│                 │     (互联网/内网)          │                 │
│  VS Code 界面   │                           │  代码仓库        │
│  打字/编辑      │                           │  Node.js 环境    │
│  显示渲染       │                           │  依赖下载        │
│                 │                           │  服务运行        │
└─────────────────┘                           └─────────────────┘
```

### 优势

| 问题 | 解决方案 |
|------|----------|
| 宿舍网络差 | 依赖在公司电脑下载，无需宿舍带宽 |

| 想用 Mac 界面 | VS Code 界面在 Mac 本地渲染 |
| 代码同步 | 无需同步，代码只在 Windows 一份 |

## 二、公司 Windows 电脑配置

### 2.1 安装 OpenSSH 服务器

#### Windows 10/11 专业版

1. **打开 Windows 设置**
   - `Win + I` → 应用 → 可选功能 → 添加功能

2. **安装 OpenSSH 服务器**
   - 搜索 "OpenSSH Server"
   - 点击安装（约 5MB）

3. **验证安装**
   ```powershell
   # 打开 PowerShell（管理员）
   Get-WindowsCapability -Online | Where-Object Name -like 'OpenSSH*'
   ```
   输出应显示 `State : Installed`

### 2.2 配置 SSH 服务开机自启

```powershell
# 以管理员身份运行 PowerShell

# 设置 SSH 服务开机自启
Set-Service -Name sshd -StartupType 'Automatic'

# 启动 SSH 服务
Start-Service sshd

# 验证服务状态
Get-Service sshd
```

### 2.3 配置防火墙

```powershell
# 允许 SSH 通过防火墙（端口 22）
New-NetFirewallRule -Name 'OpenSSH SSH Server (sshd)' -DisplayName 'OpenSSH SSH Server' -Enabled True -Direction Inbound -Protocol TCP -LocalPort 22 -Action Allow
```

### 2.4 创建专用用户（可选但推荐）

```powershell
# 创建新用户（替换 username 和 password）
net user devuser YourPassword123 /add

# 添加到管理员组（可选）
net localgroup administrators devuser /add
```

### 2.5 配置 SSH 公钥认证（推荐）

#### 在 Mac 上生成 SSH 密钥

```bash
# 在 Mac 终端执行
ssh-keygen -t ed25519 -C "your_email@example.com"
# 一路回车即可

# 查看公钥
cat ~/.ssh/id_ed25519.pub
```

#### 将公钥添加到 Windows

1. 在 Windows 上创建 authorized_keys 文件：
   ```powershell
   # 创建 .ssh 目录
   New-Item -ItemType Directory -Force -Path $env:USERPROFILE\.ssh

   # 设置权限（重要）
   icacls $env:USERPROFILE\.ssh /inheritance:r
   icacls $env:USERPROFILE\.ssh /grant "$($env:USERNAME):(F)"

   # 创建 authorized_keys 文件
   New-Item -ItemType File -Path $env:USERPROFILE\.ssh\authorized_keys
   ```

2. 将 Mac 的公钥内容复制粘贴到 `C:\Users\你的用户名\.ssh\authorized_keys`

3. 设置正确的文件权限：
   ```powershell
   icacls $env:USERPROFILE\.ssh\authorized_keys /inheritance:r
   icacls $env:USERPROFILE\.ssh\authorized_keys /grant "$($env:USERNAME):(R)"
   ```

### 2.6 获取 Windows 电脑信息

```powershell
# 查看用户名
whoami

# 查看内网 IP
ipconfig | findstr "IPv4"

# 记录以下信息：
# - 用户名：___________
# - 内网 IP:  ___________:54:32
```

## 三、宿舍 Mac 电脑配置

### 3.1 安装 VS Code

1. 下载：https://code.visualstudio.com/
2. 拖入应用程序文件夹

### 3.2 安装 Remote - SSH 插件

1. 打开 VS Code
2. 左侧活动栏 → 扩展（或 `Cmd + Shift + X`）
3. 搜索 "Remote - SSH"
4. 安装 Microsoft 出品的插件

### 3.3 配置 SSH 连接

#### 方式一：使用配置文件（推荐）

1. 打开 Mac 终端
2. 编辑 SSH 配置文件：
   ```bash
   code ~/.ssh/config
   ```

3. 添加以下内容：
   ```config
   # 公司电脑 - 直连（如果在同一内网）
   Host company-pc
       HostName 192.168.x.x          # 替换为 Windows 内网 IP
       User your-username            # 替换为 Windows 用户名
       Port 22
       IdentityFile ~/.ssh/id_ed25519
       KeepAlive yes
       ServerAliveInterval 60

   # 公司电脑 - 通过 Tailscale（推荐，更安全）
   Host company-tailscale
       HostName 100.x.x.x            # 替换为 Tailscale IP
       User your-username
       Port 22
       IdentityFile ~/.ssh/id_ed25519
       KeepAlive yes
       ServerAliveInterval 60
   ```

#### 方式二：VS Code 内配置

1. VS Code → 左下角绿色图标 → "Connect to Host"
2. 选择 "Add New SSH Host..."
3. 输入：`ssh your-username@company-ip`
4. 选择配置文件路径：`/Users/你的用户名/.ssh/config`

## 四、网络连接方案

### 方案 A：同一内网直连（简单但受限）

**适用场景**：公司和宿舍在同一网络（如都在公司园区）

**配置步骤**：
1. 确保 Windows 防火墙允许 SSH（2.3 已完成）
2. Mac 上直接 SSH 连接 Windows 内网 IP
3. 测试：`ssh your-username@192.168.x.x`

### 方案 B：Tailscale 组网（推荐）

**适用场景**：公司和宿舍不在同一网络，需要安全远程访问

#### 4.1 在 Windows 上安装 Tailscale

1. 下载：https://tailscale.com/download/windows
2. 安装后登录（可用 Google/Microsoft 账号）
3. 记录 Tailscale IP（格式：`100.x.x.x`）

#### 4.2 在 Mac 上安装 Tailscale

1. 下载：https://tailscale.com/download/macos
2. 用**同一账号**登录
3. 验证能看到两台设备

#### 4.3 配置 Tailscale 连接

1. 在 Mac 终端查看 Windows 的 Tailscale IP：
   ```bash
   tailscale status
   ```

2. 更新 SSH 配置文件（~/.ssh/config）：
   ```config
   Host company
       HostName 100.x.x.x            # Tailscale IP
       User your-username
       Port 22
       IdentityFile ~/.ssh/id_ed25519
       KeepAlive yes
       ServerAliveInterval 60
   ```

3. 测试连接：
   ```bash
   ssh company
   ```

### 方案 C：公网 IP + 端口转发（不推荐）

⚠️ **安全警告**：此方案有安全风险，仅在内网测试使用

1. 在公司路由器配置端口转发（22 端口）
2. 使用 Windows 的公网 IP
3. **必须**使用 SSH 密钥认证，禁止密码登录

## 五、项目启动流程

### 5.1 首次连接

```bash
# 在 Mac 终端
ssh company
# 首次连接会提示确认指纹，输入 yes
```

### 5.2 VS Code 远程连接

1. VS Code → 左下角绿色图标 → "Connect to Host"
2. 选择 "company"
3. 新窗口打开后，左上角显示 "SSH: company"

### 5.3 打开项目

1. VS Code → File → Open Folder
2. 浏览到项目路径：`C:\Users\你的用户名\code\Assistant`
3. 或在终端：
   ```bash
   code C:\Users\你的用户名\code\Assistant
   ```

### 5.4 启动开发环境

#### 启动后端

```bash
# 在 VS Code 终端（Windows）
cd backend
npm install              # 首次需要，依赖在 Windows 下载
npx prisma migrate dev   # 数据库迁移
npm run start:dev        # 启动后端（端口 3000）
```

#### 启动前端

```bash
# 新开一个终端（Ctrl + Shift + `）
cd frontend
npm install              # 首次需要
npm run dev              # 启动前端（端口 5173）
```

### 5.5 访问应用

在 Mac 本地浏览器访问：
- 前端：http://localhost:5173
- 后端 API: http://localhost:3000/api/v1

> ⚠️ 注意：由于是远程开发，localhost 指的是 Windows 的 localhost
> 需要在 VS Code 中配置端口转发

### 5.6 配置端口转发

1. VS Code → 左侧 → 端口 (Ports) 标签
2. 点击 "转发端口"
3. 添加：
   - `3000` → 后端 API
   - `5173` → 前端
   - `5432` → PostgreSQL（如需数据库工具）
4. 设置可见性为 "Public" 或 "Organization"

## 六、常见问题

### Q1: SSH 连接失败 "Connection refused"

**原因**：SSH 服务未启动或防火墙阻挡

**解决**：
```powershell
# Windows 上检查 SSH 服务
Get-Service sshd
# 如果未运行
Start-Service sshd

# 检查防火墙规则
Get-NetFirewallRule | Where-Object DisplayName -like '*OpenSSH*'
```

### Q2: 连接后自动断开

**原因**：网络空闲超时

**解决**：在 `~/.ssh/config` 中添加：
```config
Host company
    ServerAliveInterval 60
    ServerAliveCountMax 3
    TCPKeepAlive yes
```

### Q3: 端口转发不工作

**原因**：VS Code 端口转发未配置

**解决**：
1. 确保在 VS Code 远程窗口中
2. 检查端口转发列表（左下角 → 端口）
3. 确保 3000 和 5173 已转发

### Q4: npm install 卡在 Windows 上

**原因**：公司网络可能也有波动

**解决**：
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 或删除 node_modules 重装
rm -rf node_modules package-lock.json
npm install
```

### Q5: 路径问题 - Windows vs Mac

| 操作 | Windows 远程终端 | Mac 本地终端 |
|------|-----------------|-------------|
| 列出文件 | `dir` 或 `ls` | `ls` |
| 路径分隔符 | `\` | `/` |
| 项目路径 | `C:\Users\name\code\Assistant` | `/Users/name/code/Assistant` |

**建议**：在 VS Code 远程窗口中，所有终端命令都在 Windows 执行，使用 Windows 路径格式。

### Q6: 公司电脑关机了怎么办

**方案**：
1. 配置 Windows 唤醒（需 BIOS 支持）
2. 使用远程开机（WoL）
3. 或者：下班前不关机，只锁屏

### Q7: Tailscale 连接慢

**原因**：P2P 连接失败，流量经过中继

**解决**：
1. 确保公司网络允许 UDP 穿透
2. 在公司路由器配置 UPnP
3. 或使用方案 A（同一内网）

### Q8: PostgreSQL 连接问题

确保 Windows 上的 PostgreSQL 允许远程连接：

```powershell
# 编辑 pg_hba.conf (通常在 C:\Program Files\PostgreSQL\data\)
# 添加：
host    all             all             0.0.0.0/0               scram-sha-256

# 编辑 postgresql.conf
# 设置：
listen_addresses = '*'
```
