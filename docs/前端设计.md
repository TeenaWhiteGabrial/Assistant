## 2. 核心页面

### 2.1 首页 (/)

**功能：**
- AI 对话式输入（核心交互）
- 今日概览卡片
- 最近记录时间线

**交互流程：**
```
用户输入 → AI 实时解析 → 显示识别结果 → 确认/编辑 → 存储
```

**UI 组件：**
- 大尺寸输入框（支持多行、拖拽上传）
- 实时 AI 响应区域（流式显示）
- 智能类型预判 Badge

### 2.2 备忘录 (/memos)

**视图：**
- 列表视图：按时间/优先级排序
- 日历视图：按日期展示
- 看板视图：待办/进行中/已完成

**功能：**
- 快速添加
- 设置提醒时间
- 标记完成
- 逾期高亮

### 2.3 记账 (/bills)

**视图：**
- 月度账单日历
- 分类饼图/柱状图
- 收支趋势折线图

**功能：**
- 快速记账
- 拍照识票（OCR）
- 分类筛选
- 导出 Excel

### 2.4 工作日报 (/diaries)

**视图：**
- 日历式日报列表
- 单日报详情（时间线展示）
- 周报/月报汇总

**功能：**
- AI 自动生成草稿
- 手动补充编辑
- 导出 PDF/Markdown

### 2.5 照片墙 (/photos)

**视图：**
- 瀑布流图片墙
- 时间线相册
- 地图模式（带位置的照片）

**功能：**
- 批量上传
- AI 标签自动识别
- 语义搜索（"找出去年的聚餐照片"）
- OCR 文字搜索

### 2.6 知识库 (/knowledge)

**视图：**
- 文档列表
- 文件夹树
- 搜索结果显示

**功能：**
- 文档上传（PDF/Word/Markdown）
- AI 问答
- 相关文档推荐
- 标签管理

## 3. 核心交互设计

### 3.1 AI 输入框（全局）

```
┌─────────────────────────────────────────────────────┐
│  📝 告诉 AI 助手你想要做什么...                       │
│                                                     │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐               │
│  │ 📷 图片  │ │ 🎤 语音  │ │ 📎 文件  │  [发送]     │
│  └─────────┘ └─────────┘ └─────────┘               │
└─────────────────────────────────────────────────────┘
```

**智能解析演示：**
```
用户输入："下周一下午 3 点在会议室 A 开项目评审会，记得提醒我"

AI 解析结果：
┌─────────────────────────────────┐
│ 📋 识别为：备忘录 + 提醒          │
│ ─────────────────────────────── │
│ 事项：项目评审会                 │
│ 时间：下周一 15:00               │
│ 地点：会议室 A                   │
│ 提醒：提前 15 分钟                │
│                                   │
│ [确认创建]  [修改]                │
└─────────────────────────────────┘
```

### 3.2 流式响应

AI 处理时显示思考过程：
```
🤖 正在理解你的输入...
✓ 识别类型：记账
✓ 提取金额：35 元
✓ 识别分类：交通
✓ 创建记录成功！

💡 已为你记录：交通支出 35 元
   本月交通累计：428 元
```

## 4. 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| 框架 | React 18 + TypeScript | 类型安全 |
| 状态管理 | Zustand | 轻量级 |
| 路由 | React Router v6 | - |
| UI 组件 | Ant Design / Shadcn | - |
| 图表 | Recharts / ECharts | 数据可视化 |
| 请求 | TanStack Query | 数据获取 + 缓存 |
| 构建 | Vite | 快速开发 |
| 样式 | TailwindCSS | 原子化 CSS |

---

## 5. 响应式设计

| 断点 | 布局 |
|------|------|
| > 1200px | 三栏布局（侧边栏 + 内容 + 面板） |
| 768-1200px | 双栏布局（可折叠侧边栏） |
| < 768px | 单栏布局（底部导航） |

## 6. 页面路由

```
/           首页
/login      登录
/register   注册

/memos      备忘录列表
/memos/:id  备忘录详情

/bills      账单列表
/bills/stats 统计
/bills/:id  账单详情

/diaries    日报列表
/diaries/:date 日报详情

/photos     照片墙
/photos/:id  照片详情

/knowledge  知识库
/knowledge/:id 文档详情

/settings   设置
```
