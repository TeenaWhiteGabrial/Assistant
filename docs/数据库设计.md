# 数据库设计文档

## 1. 核心实体关系

```
┌─────────────┐
│    User     │  用户表（单账号系统，预留扩展）
└──────┬──────┘
       │ 1
       │
       │ N
┌──────▼──────────────────────────────┐
│           Entry                     │  核心记录表（所有用户输入的統一存储）
│  - id                             │
│  - user_id                        │
│  - type: enum                     │  类型：memo/bill/diary/photo/note/trip
│  - content: text                  │  原始内容
│  - structured_data: jsonb         │  AI 提取的结构化数据
│  - embedding: vector(1024)        │  向量嵌入，支持语义搜索
│  - created_at                     │
└──────┬────────────────────────────┘
       │
       ├───────────┬───────────────┬───────────────┐
       │ N         │ N             │ N             │ N
┌──────▼────┐ ┌────▼─────┐ ┌──────▼──────┐ ┌──────▼──────┐
│  Reminder │ │  Bill    │ │   Photo     │ │   Attachment│
│   提醒    │ │  记账明细 │ │   照片元数据 │ │   附件      │
└───────────┘ └───────────┘ └─────────────┘ └─────────────┘
```

## 2. 表结构设计

### 2.1 users - 用户表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| username | VARCHAR(50) | 用户名 |
| email | VARCHAR(100) | 邮箱 |
| password_hash | VARCHAR(255) | 密码哈希 |
| settings: jsonb | JSONB | 用户配置 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

### 2.2 entries - 核心记录表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 外键 → users.id |
| type | ENUM | `memo`/`bill`/`diary`/`photo`/`note`/`trip` |
| title | VARCHAR(200) | 标题（AI 生成） |
| content | TEXT | 原始内容 |
| structured_data | JSONB | AI 提取的结构化数据 |
| embedding | VECTOR(1024) | 百炼 embedding |
| status | ENUM | `pending`/`processed`/`failed` |
| created_at | TIMESTAMP | 创建时间 |

### 2.3 reminders - 提醒表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| entry_id | UUID | 外键 → entries.id |
| remind_at | TIMESTAMP | 提醒时间 |
| is_completed | BOOLEAN | 是否已完成 |
| notify_method | JSONB | 通知方式配置 |

### 2.4 bills - 记账表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| entry_id | UUID | 外键 → entries.id |
| amount | DECIMAL(10,2) | 金额 |
| category | VARCHAR(50) | 分类 |
| merchant | VARCHAR(100) | 商户 |
| bill_date | DATE | 消费日期 |
| payment_method | VARCHAR(50) | 支付方式 |

### 2.5 photos - 照片表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| entry_id | UUID | 外键 → entries.id |
| file_key | VARCHAR(255) | 对象存储 key |
| ocr_text | TEXT | OCR 识别文字 |
| ai_description | TEXT | AI 图片描述 |
| taken_at | TIMESTAMP | 拍摄时间 |
| location | GEOGRAPHY | 地理位置 |

### 2.6 attachments - 附件表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| entry_id | UUID | 外键 → entries.id |
| file_key | VARCHAR(255) | 对象存储 key |
| file_name | VARCHAR(255) | 原始文件名 |
| file_size | BIGINT | 文件大小 |
| mime_type | VARCHAR(100) | MIME 类型 |

## 3. 索引设计

```sql
-- entries 表索引
CREATE INDEX idx_entries_user_type ON entries(user_id, type);
CREATE INDEX idx_entries_created ON entries(user_id, created_at DESC);
CREATE INDEX idx_entries_embedding ON entries USING HNSW(embedding vector_cosine_ops);

-- 全文搜索索引
CREATE INDEX idx_entries_content ON entries USING GIN(to_tsvector('simple', content));

-- bills 表索引
CREATE INDEX idx_bills_date ON bills(entry_id, bill_date);
CREATE INDEX idx_bills_category ON bills(user_id, category);
```

## 4. 扩展字段说明

### entries.structured_data 示例

**备忘录类型：**
```json
{
  "time": "2026-03-05 14:00",
  "location": "公司会议室",
  "task": "项目评审会",
  "participants": ["张三", "李四"]
}
```

**记账类型：**
```json
{
  "amount": 158.00,
  "category": "餐饮",
  "merchant": "星巴克",
  "payment_method": "微信支付"
}
```

**日报类型：**
```json
{
  "date": "2026-03-03",
  "work_items": [...],
  "hours": 8,
  "mood": "good"
}
```

## 5. 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 主数据库 | PostgreSQL 15+ | 支持 JSONB + pgvector |
| 向量索引 | pgvector | HNSW 索引，支持千维向量 |
| 缓存 | Redis | 会话 + 热点数据 |
| 文件存储 | MinIO (本地) / OSS (云上) | S3 兼容协议 |
