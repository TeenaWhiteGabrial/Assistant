# AI 个人助手 - 后端架构文档

## 一、技术栈介绍

### 核心框架
| 技术 | 用途 | 通俗解释 |
|------|------|----------|
| **NestJS** | 后端主框架 | 就像一个"模板"，规定了代码怎么写、文件怎么组织 |
| **TypeScript** | 编程语言 | JavaScript 的"增强版"，写代码时有智能提示，减少错误 |
| **Prisma** | 数据库工具 | 用代码操作数据库，不用写 SQL 语句 |
| **PostgreSQL** | 数据库 | 存储数据的地方，类似 Excel 表格 |


### 2.2 认证模块 (`/api/v1/auth`)

#### 1. 用户注册
```
POST /api/v1/auth/register
```
**请求参数：**
```json
{
  "username": "张三",
  "email": "zhangsan@example.com",
  "password": "123456"
}
```
**返回结果：**
```json
{
  "code": 200,
  "data": {
    "id": "uuid...",
    "username": "张三",
    "email": "zhangsan@example.com"
  },
  "message": "注册成功"
}
```

#### 2. 用户登录
```
POST /api/v1/auth/login
```
**请求参数：**
```json
{
  "username": "张三",
  "password": "123456"
}
```
**返回结果：**
```json
{
  "code": 200,
  "data": {
    "token": "fake-jwt-token",
    "user": {
      "id": "uuid...",
      "username": "张三",
      "email": "zhangsan@example.com"
    }
  },
  "message": "登录成功"
}
```

#### 3. 获取用户信息
```
GET /api/v1/auth/profile
请求头：Authorization: Bearer <token>
```

### 2.2 记录模块 (`/api/v1/entries`)

记录模块是核心功能，用于管理用户的各种数据（备忘录、记账、日报、照片等）。

#### 1. 创建记录
```
POST /api/v1/entries
```
**请求参数：**
```json
{
  "type": "auto",  // 或 "MEMO"、"BILL"、"DIARY"、"PHOTO"、"NOTE"
  "content": "今天打车花了 50 元"
}
```
**返回结果：**
```json
{
  "code": 200,
  "data": {
    "id": "uuid...",
    "type": "BILL",
    "title": "支出记录",
    "content": "今天打车花了 50 元",
    "aiReply": "已记录：交通支出 50 元"
  },
  "message": "创建成功"
}
```

#### 2. 获取记录列表
```
GET /api/v1/entries?type=BILL&page=1&pageSize=20
```
**返回结果：**
```json
{
  "code": 200,
  "data": {
    "list": [...],
    "total": 100,
    "page": 1,
    "pageSize": 20
  },
  "message": "success"
}
```

#### 3. 获取单条记录
```
GET /api/v1/entries/:id
```

#### 4. 删除记录
```
DELETE /api/v1/entries/:id
```

## 三、代码逻辑流程

### 3.1 用户注册/登录流程

```
用户输入 → Controller(接收请求) → Service(业务逻辑) → Prisma(数据库操作) → PostgreSQL
                    ↓                                              ↑
              返回结果                                        查询/写入数据
```

**文件位置：**
- `src/auth/auth.controller.ts` - 接收 HTTP 请求
- `src/auth/auth.service.ts` - 处理业务逻辑
- `src/prisma/prisma.service.ts` - 数据库连接

### 3.2 创建记录流程（带 AI 分析）

```
用户输入"今天打车花了 50 元"
         ↓
EntryController 接收请求
         ↓
EntryService 判断 type 是否为 "auto"
         ↓
    是 → 调用 AiService.analyze()
         ↓
    AI 分析返回：{ type: "BILL", data: { amount: 50, category: "交通" } }
         ↓
创建 Entry 记录
         ↓
根据类型创建子记录（Bill、Reminder 等）
         ↓
返回结果（含 AI 回复）
```

**相关文件：**
- `src/entry/entry.controller.ts`
- `src/entry/entry.service.ts`
- `src/ai/ai.service.ts`

## 四、数据库结构

### 核心表关系

```
┌──────────────┐
│     User     │  用户表
│  id, username│

       │ 1:1
       ├──────────┬──────────┬──────────┬────────────┐
```

## 五、启动与调试

### 启动后端
```bash
cd backend

# 开发模式（自动重启）
npm run start:dev

# 调试模式（可断点）
npm run start:debug

# 生产模式
npm run build
npm run start:prod
```

### 环境变量配置
在 `backend/.env` 文件中配置：
```bash
# 数据库连接
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/assistant?schema=public"

# 阿里百炼 API Key
DASHSCOPE_API_KEY="sk-xxx"

# 服务端口
PORT=3000
```

### 常用调试命令
```bash
# 查看数据库表
docker exec postgres psql -U postgres -d assistant -c "\dt"

# 查看某张表的数据
docker exec postgres psql -U postgres -d assistant -c "SELECT * FROM \"User\";"

# 重启数据库容器
docker restart postgres
```

## 八、常见问题

### Q1: 如何添加新的 API 接口？
1. 在对应的 `controller.ts` 中添加新方法
2. 用 `@Get()`、`@Post()` 等装饰器标注路由
3. 在 `service.ts` 中实现业务逻辑

### Q2: 如何修改数据库结构？
1. 编辑 `prisma/schema.prisma`
2. 运行 `npx prisma migrate dev --name 描述变更`
3. 运行 `npx prisma generate` 生成客户端

### Q3: 如何查看日志？
后端启动后，所有请求和错误都会打印在终端。
